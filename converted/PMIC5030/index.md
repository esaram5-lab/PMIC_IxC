## Source corrections

Obvious typos in the spec tables that were corrected during conversion:

- 0x04 [3:0]: Spec lists code 0010 for '3 Errors (See R144/145 for detailed error log)'; corrected to 0011. Duplicate code in Table 109; sequence implies 0011.
- 0x04 [3:0]: Codes 0100-1110 are elided ('...') in the source; filled following the listed pattern (N errors -> fault log R(0x13E+2N)/R(0x13F+2N), ending at R15C/R15D for 15).
- 0x11 [2]: Table 122 prints 'Clear Register Table 114, Register 0x09 [2]' without the leading '1 =' used by every other bit of R11; treated as the value for code 1.
- 0x1F [7:0]: Spec lists code 000000100 for '> 250 mA'; corrected to 00000010. 9-digit code in source table; 250 mA is code 2 (125 mA/LSB).
- 0x11B [7:0]: Spec lists code 000000100 for '> 250 mA'; corrected to 00000010. 9-digit code in source table; 250 mA is code 2 (125 mA/LSB).
- 0x6A [7:0]: Spec lists code 000000100 for '> 250 mA'; corrected to 00000010. 9-digit code in source table; 250 mA is code 2 (125 mA/LSB).
- 0x6C [7:0]: Spec lists code 000000100 for '> 250 mA'; corrected to 00000010. 9-digit code in source table; 250 mA is code 2 (125 mA/LSB).
