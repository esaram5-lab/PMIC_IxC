# 4.12 DVFSQ_n Pin Function and DVFSQ State

DVFSQ (Dynamic Voltage and Frequency Scaling of the VDDQ (SWB) rail) is a low power state for LPDDR5 memory. This state introduces power saving LPDDR5 memory by lowering the operational SWB voltage value in tandem with a reduction in memory bus speed. The change in LPDDR5 memory bus speed is controlled by the controller and is transparent to PMIC functionality. The PMIC entry and exit to DVFSQ state is enabled by the DVFSQ_n input pin. DVFSQ_n is an asynchronous input signal. By default at power on, the DVFSQ_n input pin function is disabled. The host can enable the DVFSQ_n input pin function by setting Table 150, Register 0x2E [4] = ‘1’. If PMIC is selected to operate in secure mode, this register must be written when PMIC is in P2_B programmable state at initial power on prior to issuing first VR Enable command (either via I2C/I3C bus or with a pin). When in programmable or configurable lock mode, the DVFSQ_n pin can be disabled at any time when Table 114, Register 0x0A [0] = ‘0’. There are no restrictions on the number of times DVFSQ_n pin can be enabled or disabled. When DVFSQ_n pin is enabled, the voltage applied to the DVFSQ_n input pin is identified by Table 155, Register 0x33 [1].

When the DVFSQ_n input pin is enabled in the PMIC and the DVFSQ_n pin detects high to low voltage edge transition in P3 state, the PMIC enters DVFSQ state and the PMIC SWB output voltage regulator setting switches from Table 141, Register 0x25, [7:1] to Table 166, Register 0x3E [7:1] and PMIC updates Table 114, Register 0x0A [0] = ‘1’. The PMIC adjusts the SWB output voltage at a ramp rate defined in Table 150, Register 0x2E [7:6]. When DVFSQ_n pin detects low to high voltage edge transition, the PMIC exits DVFSQ state, SWB output voltage regulator setting switches from Table 166, Register 0x3E [7:1] to Table 141, Register 0x25, [7:1] and PMIC updates Table 114, Register 0x0A [0] = ‘0’. The PMIC adjusts the SWB output voltage at a ramp rate defined in Table 150, Register 0x2E [7:6]. During the output voltage transition, the PMIC masks the PWR_GOOD output signal assertion to prevent any artificial error due to crossing of the output voltage threshold setting. However, the PMIC does assert PWR_GOOD output signal if there are abnormal issues that triggers VR Disable command as described in Table 27. The PMIC does monitor PWR_GOOD input signal and executes power off config sequence registers if it is registered low when Table 154, Register 0x32 [5] = ‘1’. The PMIC DVFSQ state can only be entered from the P3 state. When operating in the PMIC DVFSQ state, the PMIC exits the DVFSQ state upon VR Disable command (either via I2C/I3C bus or with VR_EN pin), updates Table 114, Register 0x0A [0] = ‘0’ and prohibits re-entry until a high to low voltage edge transition is detected by the DVFSQ_n input pin while operating in the P3 state. It is not permitted to change the SWB output voltage related settings (Table 141, Register 0x25, [7:1], Table 147, Register 0x2B, [3], Table 166, Register 0x3E [7:1], and Table 167, Register 0x3F [2] when PMIC Table 114, Register 0x0A [0] = ‘1’. These registers must be locked when PMIC is in DVFSQ state regardless of whether PMIC enters DVFSQ state from P3_Unlocked or P3_Configurable_Lock state.

These registers are unlocked when PMIC exits DVFSQ state however they may be still locked if PMIC is operating in P3_Locked stated or P3_Configurable_Lock if Unlock input is low. Note that platform power sequencing may energize the voltage powering the DVFSQ_n input signal of the PMIC prior to turning on the VIN_Bulk input supply voltage of the PMIC. This can potentially induce a ‘back-drive’ voltage from the DVFSQ_n input signal pin to the VIN_Bulk rail. Since this can induce system instability, the PMIC must block all ‘back-drive’ paths.
