## Source corrections

Obvious typos in the spec tables that were corrected during conversion:

- 0x2B [5:3]: Bits column shows [4] but the field header says [5:3]; [5:3] is used because it makes the fields cover bits 7..0 exactly.
- 0x45 [0]: Field header says [1:0] but the Bits column shows [0]; the Bits column is used.
- 0x4D [3:0]: Field header says [1:0] but the Bits column shows [3:0]; the Bits column is used.
