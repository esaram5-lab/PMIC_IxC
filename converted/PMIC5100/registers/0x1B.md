## [7] VIN_BULK_OVER_VOLTAGE_THRESHOLD

- Description: VIN_Bulk Input Over Voltage Threshold Setting For GSI_n Assertion
- Attribute: RW — Read/Write
- Default: 0 → 5.8 V to 6 V (Varies across vendors)

| Code (bin) | Meaning |
|---|---|
| 0 | 5.8 V to 6 V (Varies across vendors) |
| 1 | Reserved |

## [6] CURRENT_OR_POWER_METER_SELECT

- Description: PMIC Output Regulator Measurement - Current or Power Meter
- Attribute: RW — Read/Write
- Default: 0 → Report Current Measurements in registers:[1]

| Code (bin) | Meaning |
|---|---|
| 0 | Report Current Measurements in registers:[1] |
| 1 | Report Power Measurements in registers[1] |

## [5] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## [4] GLOBAL_PWR_GOOD_PIN_STATUS_MASK

- Description: Global Mask PWR_GOOD Output Pin[2]
- Attribute: RW — Read/Write
- Default: 0 → Not Masked

| Code (bin) | Meaning |
|---|---|
| 0 | Not Masked |
| 1 | Masked |

## [3] GSI_N_PIN_ENABLE

- Description: Enable GSI_n Pin[3]
- Attribute: RW — Read/Write
- Default: 0 → Disable GSI_n Pin

| Code (bin) | Meaning |
|---|---|
| 0 | Disable GSI_n Pin |
| 1 | Enable GSI_n Pin |

## [2:0] PMIC_HIGH_TEMPERATURE_WARNING_THRESHOLD

- Description: PMIC High Temperature Warning Threshold[4]
- Attribute: RW — Read/Write
- Default: 101 → PMIC temperature > 125 0C

| Code (bin) | Meaning |
|---|---|
| 000 | Reserved |
| 001 | PMIC temperature > 85 0C |
| 010 | PMIC temperature > 95 0C |
| 011 | PMIC temperature > 105 0C |
| 100 | PMIC temperature > 115 0C |
| 101 | PMIC temperature > 125 0C |
| 110 | PMIC temperature > 135 0C |
| 111 | Reserved |

## Notes

- NOTE 1: Table 100, “Register 0x0C” [7:0], Table 102, “Register 0x0E” [5:0], Table 103, “Register 0x0F”[5:0].
- NOTE 2: Mask POWER_GOOD output signal for all appropriate register bits in Table 109, “Register 0x15” [5,3:2,0], Table 110, “Register 0x16” [7,5,3,1:0], Table 111, “Register 0x17” [7,5:4], Table 112, “Register 0x18” [7,5:3,1:0], and Table 113, “Register 0x19” [3:2]. Mask Register Control Table 135, “Register 0x2F” [1:0] still applies when Global PWR_GOOD output Mask register is set to ‘1’.
- NOTE 3: This register can be used as Global Mask Function for GSI_n pin. If disabled, this masks GSI_n output signal for all register bits in Table 109, “Register 0x15” [5,3,2:0], Table 110, “Register 0x16” [7,5,3,1:0], Table 111, “Register 0x17” [7,5:4], Table 112, “Register 0x18” [7,5:3,1:0], and Table 113, “Register 0x19” [3:2].
- NOTE 4: The tolerance of the temperature warning threshold is + 5 0C from the selected setting.
