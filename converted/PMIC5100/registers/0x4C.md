# PMIC5100 R4C (0x4C) — SWC_POWER_GOOD_THRESHOLD_HIGH_SIDE_VOLTAGE_SETTING, SWC_OVER_VOLTAGE_THRESHOLD_SETTING, SWC_UNDER_VOLTAGE_LOCKOUT_THRESHOLD_SETTING, SWC_OUTPUT_SOFT_STOP_TIME

## [7:6] SWC_POWER_GOOD_THRESHOLD_HIGH_SIDE_VOLTAGE_SETTING

- Description: Switch Node C Output Threshold High Side Voltage For Power Good Status
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 01 → +7.5% from the setting in Table 160, “Register 0x4B” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | +5% from the setting in Table 160, “Register 0x4B” [7:1] |
| 01 | +7.5% from the setting in Table 160, “Register 0x4B” [7:1] |
| 10 | Reserved |
| 11 | Reserved |

## [5:4] SWC_OVER_VOLTAGE_THRESHOLD_SETTING

- Description: Switch Node C Output Regulator Threshold For Over Voltage Status[1]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 10 → +12.5% from the setting in Table 160, “Register 0x4B” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | +7.5% from the setting in Table 160, “Register 0x4B” [7:1] |
| 01 | +10% from the setting in Table 160, “Register 0x4B” [7:1] |
| 10 | +12.5% from the setting in Table 160, “Register 0x4B” [7:1] |
| 11 | Reserved |

## [3:2] SWC_UNDER_VOLTAGE_LOCKOUT_THRESHOLD_SETTING

- Description: Switch Node C Output Regulator Threshold For Under Voltage Lockout Status
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 00 → -10% from the setting in Table 160, “Register 0x4B” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | -10% from the setting in Table 160, “Register 0x4B” [7:1] |
| 01 | -12.5% from the setting in Table 160, “Register 0x4B” [7:1] |
| 10 | Reserved |
| 11 | Reserved |

## [1:0] SWC_OUTPUT_SOFT_STOP_TIME

- Description: SWC Output Regulator Soft Stop Time After VR Disable[2]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 00 → 1 ms

| Code (bin) | Meaning |
|---|---|
| 00 | 1 ms |
| 01 | 2 ms |
| 10 | 4 ms |
| 11 | 8 ms |

## Notes

- NOTE 1: The setting for the Over Voltage must be higher than Power Good High Side Voltage threshold in Table 161, “Register 0x4C”[7:6].
- NOTE 2: This is the time it takes for buck regulator to go from steady state voltage to 0 V.
