# PMIC5100 R5E (0x5E) — SWB_OUTPUT_SOFT_START_TIME, SWC_OUTPUT_SOFT_START_TIME

Region: DIMM Vendor Region (NVM, password protected) | Source: JESD301-2 Table 172, p.168

| Bits | Field | Attribute | Default |
|---|---|---|---|
| 7:5 | SWB_OUTPUT_SOFT_START_TIME | RWPE | 001 |
| 4 | RESERVED | RV | 0 |
| 3:1 | SWC_OUTPUT_SOFT_START_TIME | RWPE | 001 |
| 0 | RESERVED | RV | 0 |

## [7:5] SWB_OUTPUT_SOFT_START_TIME

- Description: SWB Output Regulator Soft Start Time After VR Enable[1],[2]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 001 → 2 ms

| Code (bin) | Meaning |
|---|---|
| 000 | 1 ms |
| 001 | 2 ms |
| 010 | 4 ms |
| 011 | 6 ms |
| 100 * | 8 ms |
| 101 * | 10 ms |
| 110 * | 12 ms |
| 111 | 14 ms |

* Filled in from the listed pattern; the spec abbreviates this range with '...'.

## [4] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## [3:1] SWC_OUTPUT_SOFT_START_TIME

- Description: SWC Output Regulator Soft Start Time After VR Enable[1]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 001 → 2 ms

| Code (bin) | Meaning |
|---|---|
| 000 | 1 ms |
| 001 | 2 ms |
| 010 | 4 ms |
| 011 | 6 ms |
| 100 * | 8 ms |
| 101 * | 10 ms |
| 110 * | 12 ms |
| 111 | 14 ms |

* Filled in from the listed pattern; the spec abbreviates this range with '...'.

## [0] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## Notes

- NOTE 1: This is the time it takes for buck regulator to go from 0 V to steady state voltage (the actual voltage varies based on pre-programmed voltage)
- NOTE 2: Only applicable if Table 164, “Register 0x4F” [0] = ‘0’. This bit is a don’t care when Table 164, “Register 0x4F” [0] = ‘1’.
