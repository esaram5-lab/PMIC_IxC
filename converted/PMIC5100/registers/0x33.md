# PMIC5100 R33 (0x33) — TEMPERATURE_MEASUREMENT, VOUT_1.0V_OUTPUT_POWER_GOOD_STATUS

Region: Host Region | Source: JESD301-2 Table 139, p.150

| Bits | Field | Attribute | Default |
|---|---|---|---|
| 7:5 | TEMPERATURE_MEASUREMENT | RO | 0 |
| 4:3 | RESERVED | RV | 0 |
| 2 | VOUT_1.0V_OUTPUT_POWER_GOOD_STATUS | RO | 0 |
| 1:0 | RESERVED | RV | 0 |

## [7:5] TEMPERATURE_MEASUREMENT

- Description: PMIC Temperature[1]
- Attribute: RO — Read Only (writes have no effect)
- Default: 0

| Code (bin) | Meaning |
|---|---|
| 000 | < 85 0C |
| 001 | 85 0C |
| 010 | 95 0C |
| 011 | 105 0C |
| 100 | 115 0C |
| 101 | 125 0C |
| 110 | 135 0C |
| 111 | > 140 0C |

## [4:3] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## [2] VOUT_1.0V_OUTPUT_POWER_GOOD_STATUS

- Description: VOUT_1.0V LDO Output Power Good Status[2]
- Attribute: RO — Read Only (writes have no effect)
- Default: 0 → Power Good

| Code (bin) | Meaning |
|---|---|
| 0 | Power Good |
| 1 | Power Not Good |

## [1:0] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## Notes

- NOTE 1: The accuracy of the temperature readout code is + 5 0C.
- NOTE 2: This register is set when VOUT_1.0V output drops below the threshold setting in register Table 114, “Register 0x1A” [0].
