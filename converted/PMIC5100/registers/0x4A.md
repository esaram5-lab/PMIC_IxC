## [7:6] SWB_POWER_GOOD_THRESHOLD_HIGH_SIDE_VOLTAGE_SETTING

- Description: Switch Node B Output Threshold High Side Voltage For Power Good Status
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 01 → +7.5% from the setting in Table 158, “Register 0x49” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | +5% from the setting in Table 158, “Register 0x49” [7:1] |
| 01 | +7.5% from the setting in Table 158, “Register 0x49” [7:1] |
| 10 | +10% from the setting in Table 158, “Register 0x49” [7:1] |
| 11 | Reserved |

## [5:4] SWB_OVER_VOLTAGE_THRESHOLD_SETTING

- Description: Switch Node B Output Regulator Threshold For Over Voltage Status[2]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 10 → +12.5% from the setting in Table 158, “Register 0x49” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | +7.5% from the setting in Table 158, “Register 0x49” [7:1] |
| 01 | +10% from the setting in Table 158, “Register 0x49” [7:1] |
| 10 | +12.5% from the setting in Table 158, “Register 0x49” [7:1] |
| 11 | Reserved |

## [3:2] SWB_UNDER_VOLTAGE_LOCKOUT_THRESHOLD_SETTING

- Description: Switch Node B Output Regulator Threshold For Under Voltage Lockout Status
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 00 → -10% from the setting in Table 158, “Register 0x49” [7:1]

| Code (bin) | Meaning |
|---|---|
| 00 | -10% from the setting in Table 158, “Register 0x49” [7:1] |
| 01 | -12.5% from the setting in Table 158, “Register 0x49” [7:1] |
| 10 | Reserved |
| 11 | Reserved |

## [1:0] SWB_OUTPUT_SOFT_STOP_TIME

- Description: SWB Output Regulator Soft Stop Time After VR Disable[3]
- Attribute: RWPE — Read/Write; Protected (writable only after the password is written); Persistent across power cycle, erasable by command
- Default: 00 → 0.5 ms

| Code (bin) | Meaning |
|---|---|
| 00 | 0.5 ms |
| 01 | 1 ms |
| 10 | 2 ms |
| 11 | 4 ms |

## Notes

- NOTE 1: Only applicable if Table 164, “Register 0x4F” [0] = ‘0’.
- NOTE 2: The setting for the Over Voltage must be higher than Power Good High Side Voltage threshold in Table 159, “Register 0x4A”[7:6].
- NOTE 3: This is the time it takes for buck regulator to go from steady state voltage to 0 V.
