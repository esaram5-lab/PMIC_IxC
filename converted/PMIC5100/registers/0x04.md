## [7] GLOBAL_ERROR_COUNT

- Description: Global Error Count Since Last Erase Operation[3]
- Attribute: ROE — Read Only (writes have no effect); Persistent across power cycle, erasable by command
- Default: 0 → No Error or Only 1 Error since last Erase operation

| Code (bin) | Meaning |
|---|---|
| 0 | No Error or Only 1 Error since last Erase operation |
| 1 | > 1 Error Count since last Erase operation |

## [6] GLOBAL_ERROR_LOG_BUCK_OV_OR_UV

- Description: Global Error Log History for Buck Regulator Output Over or Under Voltage[4]
- Attribute: ROE — Read Only (writes have no effect); Persistent across power cycle, erasable by command
- Default: 0 → No Error Occurred

| Code (bin) | Meaning |
|---|---|
| 0 | No Error Occurred |
| 1 | Error Occurred |

## [5] GLOBAL_ERROR_LOG_VIN_BULK_OVER_VOLTAGE

- Description: Global Error Log History for VIN_Bulk Over Voltage[4]
- Attribute: ROE — Read Only (writes have no effect); Persistent across power cycle, erasable by command
- Default: 0 → No Error Occurred

| Code (bin) | Meaning |
|---|---|
| 0 | No Error Occurred |
| 1 | Error Occurred |

## [4] GLOBAL_ERROR_LOG_CRITICAL_TEMPERATURE

- Description: Global Error Log History for Critical Temperature[4]
- Attribute: ROE — Read Only (writes have no effect); Persistent across power cycle, erasable by command
- Default: 0 → No Error Occurred

| Code (bin) | Meaning |
|---|---|
| 0 | No Error Occurred |
| 1 | Error Occurred |

## [3:0] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## Notes

- NOTE 1: The PMIC always attempts to write this register into its non-volatile memory. However, it may not be guaranteed depending on how fast the host may shut off the input power to the PMIC. The PMIC needs minimum of 4.5 V for VIN_Bulk voltage and 200 ms duration from PWR_GOOD signal assertion to guarantee the write operation into non-volatile memory.
- NOTE 2: Host must explicitly perform Erase operation to erase this entire register via command in Table 144, “Register 0x39”. The PMIC needs minimum of 200 ms for Erase operation.
- NOTE 3: PMIC counts the error since last erase operation and if more than one error occurs, it sets this bit to ‘1’. Host must explicitly perform Erase operation to erase this entire register Table 92, “Register 0x04” [7:0].
- NOTE 4: PMIC sets the bit when error occurs.
