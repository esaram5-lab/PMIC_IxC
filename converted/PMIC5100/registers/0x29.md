# PMIC5100 R29 (0x29) — SWA_MODE_SELECT, SWA_SWITCHING_FREQ

Region: Host Region | Source: JESD301-2 Table 129, p.142

| Bits | Field | Attribute | Default |
|---|---|---|---|
| 7:6 | SWA_MODE_SELECT | RW | 10 |
| 5:4 | SWA_SWITCHING_FREQ | RW | 00 |
| 3:0 | RESERVED | RV | 0 |

## [7:6] SWA_MODE_SELECT

- Description: Switch Node A Output Regulator Mode Selection
- Attribute: RW — Read/Write
- Default: 10 → COT; DCM (Constant on Time; Discontinuous Current Mode)

| Code (bin) | Meaning |
|---|---|
| 00 | Reserved |
| 01 | Reserved |
| 10 | COT; DCM (Constant on Time; Discontinuous Current Mode) |
| 11 | COT; Forced CCM (Constant on Time; Continuous Current Mode) |

## [5:4] SWA_SWITCHING_FREQ

- Description: Switch Node A Output Regulator Switching Frequency
- Attribute: RW — Read/Write
- Default: 00 → 750 KHz

| Code (bin) | Meaning |
|---|---|
| 00 | 750 KHz |
| 01 | Vendor Specific |
| 10 | Vendor Specific |
| 11 | Vendor Specific |

## [3:0] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## Notes

- NOTE 1: At first power on, this register is automatically configured identically by PMIC on its own as Table 162, “Register 0x4D”.
- NOTE 2: If required, the host must adjust this register first before issuing VR Enable command in Table 138, “Register 0x32” [7].
