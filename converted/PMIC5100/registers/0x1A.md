## [7:5] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

## [4] QUIESCENT_STATE_EN

- Description: PMIC Quiescent State Entry Enable[1]
- Attribute: RW — Read/Write
- Default: 0 → Disable

| Code (bin) | Meaning |
|---|---|
| 0 | Disable |
| 1 | Enable[2],[3] |

## [3] RESERVED

- Description: Reserved
- Attribute: RV — Reserved (reads 0; host must not modify)
- Default: 0

- Description: VOUT 1.8V LDO Output Threshold Voltage for Power Good Status
- Attribute: RW — Read/Write
- Default: 0 → 1.6 V

| Code (bin) | Meaning |
|---|---|
| 0 | 1.6 V |
| 1 | Reserved |

## [1] OUTPUT_POWER_SELECT

- Description: Switch Regulator Output Power Select[4]
- Attribute: RW — Read/Write
- Default: 0 → Report individual power for each rail in R0C, R0E, and R0F

| Code (bin) | Meaning |
|---|---|
| 0 | Report individual power for each rail in R0C, R0E, and R0F |
| 1 | Report total power of each rail in R0C5 |

## [0] VOUT_1.0V_POWER_GOOD_THRESHOLD_VOLTAGE

- Description: VOUT 1.0V LDO Output Threshold Voltage for Power Good Status
- Attribute: RW — Read/Write
- Default: 0 → -10% from the setting in Table 166, “Register 0x51” [2:1]

| Code (bin) | Meaning |
|---|---|
| 0 | -10% from the setting in Table 166, “Register 0x51” [2:1] |
| 1 | -15% from the setting in Table 166, “Register 0x51” [2:1] |

## Notes

- NOTE 1: This bit must be configured before issuing VR Enable command.
- NOTE 2: VR Disable command (VR_EN pin transition to low or Table 138, “Register 0x32” [7] = ‘0’ (in programmable mode only)) puts PMIC in Quiescent state.
- NOTE 3: Simultaneous usage of programmable mode (i.e., Table 135, “Register 0x2F” [2] = ‘1’), PWR_GOOD as IO (i.e., Table 138, “Register 0x32” [5] = ‘1’) and P1 State Enable (i.e., Table 114, “Register 0x1A” [4] = ‘1’) is considered an illegal configuration when VR_EN pin is intended to be used; otherwise it is a valid configuration if VR_EN command is used on I2C/I3C Basic bus.
- NOTE 4: This register is only applicable if Table 115, “Register 0x1B” [6] = ‘1’.
- NOTE 5: Host should only read Table 100, “Register 0x0C” [7:0] for total power. The register contents of Table 102, “Register 0x0E” and Table 103, “Register 0x0F” may not be valid.
