# PMIC5100 R2A (0x2A) — SWB_MODE_SELECT, SWB_SWITCHING_FREQ, SWC_MODE_SELECT, SWC_SWITCHING_FREQ

Region: Host Region | Source: JESD301-2 Table 130, p.143

| Bits | Field | Attribute | Default |
|---|---|---|---|
| 7:6 | SWB_MODE_SELECT | RW | 10 |
| 5:4 | SWB_SWITCHING_FREQ | RW | 00 |
| 3:2 | SWC_MODE_SELECT | RW | 10 |
| 1:0 | SWC_SWITCHING_FREQ | RW | 01 |

## [7:6] SWB_MODE_SELECT

- Description: Switch Node B Output Regulator Mode Selection[3]
- Attribute: RW — Read/Write
- Default: 10 → COT; DCM (Constant on Time; Discontinuous Current Mode)

| Code (bin) | Meaning |
|---|---|
| 00 | Reserved |
| 01 | Reserved |
| 10 | COT; DCM (Constant on Time; Discontinuous Current Mode) |
| 11 | COT; Forced CCM (Constant on Time; Continuous Current Mode) |

## [5:4] SWB_SWITCHING_FREQ

- Description: Switch Node B Output Regulator Switching Frequency[3]
- Attribute: RW — Read/Write
- Default: 00 → 750 KHz

| Code (bin) | Meaning |
|---|---|
| 00 | 750 KHz |
| 01 | Vendor Specific |
| 10 | Vendor Specific |
| 11 | Vendor Specific |

## [3:2] SWC_MODE_SELECT

- Description: Switch Node C Output Regulator Mode Selection
- Attribute: RW — Read/Write
- Default: 10 → COT; DCM (Constant on Time; Discontinuous Current Mode)

| Code (bin) | Meaning |
|---|---|
| 00 | Reserved |
| 01 | Reserved |
| 10 | COT; DCM (Constant on Time; Discontinuous Current Mode) |
| 11 | COT; Forced CCM (Constant on Time; Continuous Current Mode) |

## [1:0] SWC_SWITCHING_FREQ

- Description: Switch Node C Output Regulator Switching Frequency
- Attribute: RW — Read/Write
- Default: 01 → Vendor Specific

| Code (bin) | Meaning |
|---|---|
| 00 | 750 KHz |
| 01 | Vendor Specific |
| 10 | Vendor Specific |
| 11 | Vendor Specific |

## Notes

- NOTE 1: At first power on, this register is automatically configured identically by PMIC on its own as Table 163, “Register 0x4E”.
- NOTE 2: If required, the host must adjust this register first before issuing VR Enable command in Table 138, “Register 0x32” [7].
- NOTE 3: Only applicable if Table 164, “Register 0x4F” [0] = ‘0’.
